A status pill shows where a cycle or section is: Draft, In review, Approved, Published or Off plan.

The consumer provides the status key; the pill supplies the word. Pills are uppercase, 11px, 700 weight with 0.08em tracking and 2px bevelled corners, a tint fill with matching text and no outline. Always show the word, never colour alone. Off plan is the only err (brick) status. Do not invent further states; map new ones onto these five. The mockup also uses ok, warn and info tints for validation results.
